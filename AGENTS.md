# TugWatch Pro — Native Google Antigravity Rules & Directives

## Architecture Directives
- **Google Antigravity Natively**: Automated workspace integration, rule enforcement, and progressive skills.
- **Polycodegraph**: Multi-language semantic AST dependency graph between UI, local storage DB, and Firebase Cloud.
- **Code-Review-Graph**: Comprehensive dependency sweeps, integrity auditing, and schema validation.
- **RTK + Token Savior**: Redux Toolkit state pattern with sparse token-compression layer saving 70-85% LLM tokens.
